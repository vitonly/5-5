# Шрифты сайта

Лежат прямо в проекте, чтобы сборка не скачивала их из Google Fonts
(если Google не ответит — сборка падает).

| Файл | Шрифт | Где на сайте | Лицензия |
|------|-------|--------------|----------|
| `Unbounded.woff2` | Unbounded, начертания 600–700 | заголовки | `OFL-Unbounded.txt` |
| `StartSans.woff2` | IBM Plex Sans, начертания 400–600 | основной текст | `OFL-IBMPlexSans.txt` |
| `JetBrainsMono.woff2` | JetBrains Mono, начертания 500–700 | цифры | `OFL-JetBrainsMono.txt` |

Взяты из github.com/google/fonts, оставлены только латиница и кириллица
(как раньше отдавал Google) и нужные начертания. У IBM Plex зарезервировано имя «Plex»,
поэтому изменённый файл переименован в Start Sans — так требует лицензия OFL.
