# Своя игра

Работает двумя способами из одного и того же кода:
на сайте startdota.ru (основной) и как приложение для локальной сети класса без интернета (запасной).

## Основной вариант. На сайте startdota.ru

- Ученики: вкладка **«Своя игра»** в меню сайта → https://startdota.ru/igra/. Имя берётся из профиля, ставить ничего не нужно.
- Ведущий (только админ сайта): вкладка «Своя игра» в админском меню → https://startdota.ru/igra/host.
- Табло для проектора: кнопка «Открыть табло для проектора» на пульте.
- После игры на пульте — «Начислить очки школы» за 1/2/3 место (по умолчанию 1 / 0.5 / 0.3,
  при равенстве счёта место общее). Повторно за ту же игру не начисляется.
- Паки: кнопка «Добавить .siq» на пульте (хранятся на сервере в /var/www/startplus/igra/packs).

Как устроено: игра — отдельная служба `svoya-igra` (systemd) на порту 8090, nginx отдаёт её по /igra/.
Кто вошёл, служба спрашивает у сайта (`/api/igra/me`), очки начисляет через `/api/igra/award`.
Выкладка: `python scripts/vps_igra_deploy.py` из корня репозитория (нужен тот же SSH-ключ, что и для сайта).
Логи: `journalctl -u svoya-igra -f`.

## Запасной вариант. Приложение SvoyaIgra.exe (класс без интернета)

Один и тот же файл ставится и ведущему, и ученикам. Окно открывается на весь экран.
Ученики жмут «Играть» — приложение само находит игру в сети класса.

### Сборка (один раз, дома)

1. Установите Python 3.12 с python.org. В установщике отметьте **Add Python to PATH**.
2. Запустите `build.bat`. Нужен интернет, сборка идёт пару минут.
3. В папке появится `SvoyaIgra.exe`. Python больше не нужен.

### В классе

1. Скопируйте `SvoyaIgra.exe` на свой компьютер и на компьютеры учеников (например, на рабочий стол).
2. У себя запустите exe → **«Вести игру»**. Windows спросит про доступ к сети — разрешите
   **для частных сетей**. Если окна не было или нужны права администратора — попросите админа
   разрешить SvoyaIgra.exe в брандмауэре.
3. На пульте нажмите **«Открыть табло для проектора»**. Если проектор подключён вторым экраном,
   табло само откроется на нём. Закрыть табло — Alt+F4.
4. Ученики запускают exe → **«Играть»** → выбирают вашу игру в списке.
   Если список пустой — вводят адрес с пульта ведущего (вида `192.168.x.x`).
5. Выйти из приложения — кнопка «Выход» в правом верхнем углу.

Паки `.siq` кладите в папку `packs`, которая появится рядом с exe у ведущего.

Возможные проблемы:
- **Антивирус ругается на exe.** Так бывает с программами, собранными PyInstaller.
  Добавьте файл в исключения антивируса.
- **Окно не открывается.** Нужен компонент Microsoft Edge WebView2 — в Windows 10/11 он обычно уже есть.

## Ещё вариант. Через браузер в локальной сети (без сборки exe)

1. Установите Python 3.10+ (с галочкой **Add Python to PATH**) и запустите `start.bat`.
2. Ведущий открывает **http://localhost:8080/host**, табло — **http://localhost:8080/screen**.
3. Ученики открывают в браузере адрес из окна сервера (вида `http://192.168.x.x:8080`).

## Паки вопросов

- Кладите `.siq` в папку `packs` или добавляйте кнопкой «Добавить .siq» на пульте.
- Подходят паки из SIGame и паки, сделанные в редакторе вопросов SIGame.
- `Демо-пак.siq` нужен для проверки: в нём есть текст, картинки, звук и видео.
- Видео лучше в формате mp4 (H.264): его показывают все браузеры.

## Правила

- Каждый сам за себя. Вопрос выбирает тот, кто последним ответил верно.
- В начале раунда показываются все его темы.
- Текст вопроса «печатается» постепенно (скорость — в настройках). Кнопка открывается,
  когда вопрос прочитан или доиграл звук/видео. Нажатие раньше — фальстарт, кнопка блокируется на 1 секунду.
- Отвечают вслух. Ведущий жмёт «Верно» или «Неверно». За неверный ответ стоимость вычитается,
  и остальные могут жать снова.
- Кто нажал первым, решает сервер. Задержка сети каждого ученика учитывается.

### Особые вопросы (берутся из пака)

- **Кот в мешке.** Выбравший отдаёт вопрос другому игроку. Если в паке задан диапазон цены,
  получатель выбирает цену. Отвечает только получатель: ± цена.
- **Аукцион.** Игроки по очереди ставят: ставка, ва-банк или пас. Первым ходит выбравший, ему пасовать нельзя.
  Отвечает победитель аукциона: ± ставка.
- **Без риска.** Отвечает выбравший: верно — двойная цена, неверно — ничего не теряет.
- **Для всех.** Все пишут ответ у себя, ведущий отмечает каждый ответ, каждому ± цена.

### Финал

- Играют только те, у кого больше нуля.
- По очереди убирают темы (начинает тот, у кого меньше очков), пока не останется одна.
  В настройках можно включить «играть все финальные темы».
- Каждый финалист тайно ставит от 1 до своего счёта, потом пишет ответ. Ведущий отмечает ответы: ± ставка.

### Пульт ведущего

- Видит правильный ответ заранее (ещё до показа вопроса) и неправильные ответы из пака.
- Меняет очки (клик по очкам), передаёт ход (★), удаляет игроков, пропускает вопросы и раунды.
- Может действовать за игрока: отдать кота, сделать ставку, убрать тему — если игрок не в сети.
- **Пауза** останавливает таймеры, звук и видео у всех.
- **Апелляции.** Если ведущий не засчитал ответ, игрок может нажать «Оспорить решение».
  Ведущий принимает (игрок получает очки как за верный ответ) или отклоняет. Отключается в настройках.

## Горячие клавиши ведущего

| Клавиша | Действие |
|---|---|
| 1 | Верно |
| 2 | Неверно |
| O | Открыть кнопки / закончить чтение |
| S | Пропустить вопрос |
| N | Дальше (к табло) / пропустить заставку |
| P | Пауза / продолжить |

У игроков кнопка ответа — **Пробел**.

## Пока не сделано

- Встроенный редактор вопросов (этап 3). Пока паки делаются в редакторе вопросов SIGame.
- Вопросы с вариантами ответа и статистика игры — по желанию.

## Файлы

- `app.py` — приложение: стартовый экран, поиск игры в сети, окна
- `build.bat` — сборка SvoyaIgra.exe
- `server.py` — сервер (страницы, связь с браузерами, раздача медиа)
- `game.py` — правила и ход игры
- `siq.py` — чтение паков SIGame
- `static/` — страницы: стартовый экран (`launcher`), игрок (`player`), ведущий (`host`), табло (`screen`)
